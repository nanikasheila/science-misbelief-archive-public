# 科学的誤認・疑似科学・境界領域事件アーカイブ

Science Misbelief & Pseudoscience Boundary Archive

この公開リポジトリを記事編集の正本とします。記事の変更をmainへpushすると、検証後にWebサイトが自動更新されます。

科学史における誤認、観測限界、実験汚染、社会的熱狂、科学と疑似科学の境界に加え、危険認識や安全対策が問題となった科学・技術事故を、日本語の事例記事として整理する継続型資料集です。誤認が生まれ、検証され、説明や対策が更新される過程を比較し、科学啓蒙や創作のための調査の入口にします。収録は研究者への不正認定や、当時の仮説を一律に疑似科学と呼ぶことを意味しません。

## 収録方針とこれまでの整備

2026-09-30の拡充時点では、初版12件に22件を加え、**全34件（出典確認済み31件／未検証候補3件）**となりました。最新の記事数・内訳は自動生成するWeb一覧・Markdown索引に表示します。[リセンコ農法](cases/lysenko-agriculture.md)、[武器軟膏](cases/weapon-salve.md)、[四体液説](cases/four-humours.md)から、現代の観測・生命科学の事例までを追加しました。出典確認済みは「この記事が示す範囲の根拠を読んだ」という編集状態です。原著全文まで確認できたか、機関解説・要旨までかは各記事の出典節を参照してください。歴史上の全論点が解決済みという意味ではありません。

追加記事では学説史、科学的誤認、研究不正、未確立の起源解釈を「事例区分」で区別します。[大陸移動説](cases/continental-drift.md)と[ピロリ菌](cases/helicobacter-pylori.md)は後に支持された**対照例**で、疑似科学や誤説として数えるための収録ではありません。[ALH84001](cases/alh84001.md)も、火星生命全般が否定された事件とは扱いません。

未特定の発光細菌、高温超伝導誤報、メタマテリアル超光速の3件は、事件が実在したという根拠を確認できるまで保留します。元のファイル名を維持し、未確認の筋書きを事実として掲載しません。

2026-10-01には科学・技術事故に続き、[サリドマイド](cases/thalidomide.md)や[森永ヒ素ミルク](cases/morinaga-arsenic-milk-1955.md)、[Comet](cases/comet-fatigue-1954.md)、[ネブリウム](cases/nebulium.md)などを追加しました。[Semmelweisの手指消毒](cases/semmelweis-handwashing.md)は有効な介入の対照例です。実在する信号や観測差の説明が変わった事例には「原因帰属・モデルの不完全さ」を設け、観測自体の誤りと区別します。

## 対象と編集方針

- 科学者による観測・実験・解析の誤認と、その訂正。
- 理論的な前提、社会・政治・メディアと科学的評価の関係。
- 疑似科学・神秘主義と科学の交錯、技術用語の誤解。
- 長期残留物質等の危険性の誤評価。ただし事故の存在だけで「科学的誤認」と認定せず、誰のどの評価が問題だったかを示す。
- 科学・技術事故における危険の認識、防護具、安全情報、管理制度の問題。[リア放射線事故](cases/lia-radiological-accident-2001.md)や[Wetterhahnの研究室事故](cases/wetterhahn-dimethylmercury-1996.md)を含む。当時入手できた知識と事故後の検証を分け、被害者の不注意や疑似科学へ短絡しない。
- 変容しながら続いた学説史と、追加の証拠によって支持された新説の対照例。

当時の主張、確認された事実、編集者の原因分析を分けます。出典のない固有名・年代・反証の物語は補完せず留保します。YouTubeと自動抽出は候補探しに使い、原論文・調査報告・機関資料等で照合します。調査用の元データや内部記録は、この公開リポジトリには含めません。

## 編集と確認

GitHubなどのMarkdownビューアでは各記事をビルドなしで読めます。生成・検査にはNode.js 22以降を使います。追加パッケージは不要です。

```sh
node scripts/build.mjs
git diff --check
```

構造チェックは事実確認を代替しません。AIによる半自動編集でも、出典を読み、更新後の差分を確認してください。新規事例は[テンプレート](templates/case.md)を `cases/<slug>.md` に複製して記入するだけで、索引・記事数・分類・検索データへ反映されます。既存カテゴリを使う限り、記事以外のファイルの更新は不要です。下書き・内部メモは `cases/` に置かないでください。

## Webサイト

記事一覧、本文検索、分類・確認状態の絞り込み、関連記事・出典を辿れる静的サイトを生成できます。人が記した関連記事に加え、共通分類の候補も自動表示します。公開範囲は `cases/*.md` と固定の一般向け説明・アセットに限定し、内部監査や調査用データを除きます。

```sh
node scripts/build.mjs
node --test tests/archive.test.mjs
```

生成先は `_site/` です。Web一覧は `index.html`、Markdownの全件・分類別索引は `catalog.md` として毎回生成します。手動の許可リストや記事表の二重管理は不要です。PRとmainへのpushでCIも同じテスト・生成を実行し、mainで成功するとGitHub Pagesへ自動配信します。[サイトのビルド・公開手順](docs/site.md)を参照してください。リポジトリ自体も公開されるため、サイトに含めない文書やGit履歴も閲覧可能です。秘密情報や非公開資料はコミットしないでください。
